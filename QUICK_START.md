# Quick Start Guide 🚀

## Ready to Use! ✅

Your Stock Market Analyzer is fully installed and tested. Here's how to use it immediately:

## Option 1: Command Line Interface (CLI)

```bash
python3 stock_market_analyzer.py
```

**Features:**
- Interactive menu with 5 options
- Single stock analysis
- Multiple stock comparison
- Market overview
- Detailed console output

## Option 2: Web Interface (Recommended)

```bash
python3 stock_web_app.py
```

Then open your browser to: **http://localhost:5000**

**Features:**
- Modern web interface
- Real-time data visualization
- Quick analysis from homepage
- Comprehensive analysis pages
- Stock comparison tools
- Market overview dashboard

## What You Get

### 📊 Real-Time Data
- Current stock prices
- Daily changes and volume
- Market capitalization

### 📈 Technical Analysis
- **RSI**: Currently 33.28 (Oversold territory - potential buy signal)
- **MACD**: Momentum indicator
- **Moving Averages**: SMA 20, 50, 200
- **Support/Resistance**: Key price levels

### 💰 Fundamental Analysis
- **P/E Ratio**: Valuation metric
- **Debt-to-Equity**: Financial health
- **ROE/ROA**: Profitability metrics
- **Growth Rates**: Revenue and earnings

### ⚠️ Risk Metrics
- **Volatility**: Price fluctuation measure
- **Beta**: Market correlation
- **Sharpe Ratio**: Risk-adjusted returns
- **Max Drawdown**: Worst-case scenario

### 🎯 Trading Signals
- **Overall Signal**: BUY/SELL/HOLD recommendation
- **Technical Signals**: Based on indicators
- **Fundamental Signals**: Based on ratios

## Troubleshooting

### If you get errors:
1. **Check internet connection** - The app needs real-time data
2. **Try a different stock symbol** - Some symbols may not be available
3. **Wait a moment** - Yahoo Finance has rate limits
4. **Restart the program** - If it gets stuck

### Common symbols that always work:
- SPY, QQQ, AAPL, MSFT, GOOGL
